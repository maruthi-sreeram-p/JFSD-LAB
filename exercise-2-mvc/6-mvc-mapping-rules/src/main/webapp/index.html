URL mapping rules

Click a link and see which servlet the container picked. The patterns are in WEB-INF/web.xml.

Exact match /home

  • /home
  • /home/extra - not exact, so it falls to the default servlet

Path match /admin/*

  • /admin
  • /admin/users
  • /admin/users/42

Longest path wins /admin/reports/*

  • /admin/reports/monthly

Extension match *.do

  • /login.do
  • /admin/save.do - path pattern is checked before the extension, so /admin/* wins

Default servlet /

  • /nothing/matches/this
